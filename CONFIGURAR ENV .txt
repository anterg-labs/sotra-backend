CONFIGURAR POSTGRESQL CON ARCHIVO .ENV

1. Abrir una terminal en la carpeta raíz del proyecto.
   Debe estar visible el archivo SOTRA-BACKEND.csproj.

2. Copiar el archivo de ejemplo a uno real:
   copia .env.example y renómbralo como .env

3. Editar el archivo .env con los datos de tu entorno:
   DB_HOST=localhost
   DB_PORT=5432
   DB_NAME=sotra
   DB_USER=TU_USUARIO
   DB_PASSWORD=TU_PASSWORD

4. Verificar que SotraContext.cs lea las variables desde .env.
   El proyecto ya está preparado para cargar las variables con DotNetEnv.

5. No subir el archivo .env al repositorio.
   El archivo .gitignore ya debe excluirlo.

6. Comprobar que compila:
   dotnet build

7. Comprobar Entity Framework:
   dotnet ef dbcontext info --context SotraContext

IMPORTANTE:
- No escribir usuario ni contraseña directamente en SotraContext.cs.
- Cada desarrollador debe tener su propio archivo .env local.
- El archivo .env.example sí se puede compartir en Git como plantilla.
- Si cambian los datos de conexión, solo hay que actualizar el archivo .env local.
