CONFIGURAR POSTGRESQL CON USER SECRETS

1. Abrir una terminal en la carpeta donde está:
   SOTRA-BACKEND.csproj

2. Guardar la conexión en User Secrets:
   dotnet user-secrets set "ConnectionStrings:SotraConnection" "Host=localhost;Port=5432;Database=sotra;Username=TU_USUARIO;Password=TU_PASSWORD"

3. Verificar que se guardó:
   dotnet user-secrets list

4. En SotraContext.cs, la conexión debe leerse desde User Secrets:

   var configuration = new ConfigurationBuilder()
       .AddUserSecrets<SotraContext>()
       .Build();

   var connectionString =
       configuration.GetConnectionString("SotraConnection");

   optionsBuilder.UseNpgsql(connectionString);

5. Si falta soporte para User Secrets:
   dotnet add package Microsoft.Extensions.Configuration.UserSecrets

6. Comprobar que compila:
   dotnet build

7. Comprobar Entity Framework:
   dotnet ef dbcontext info --context SotraContext

IMPORTANTE:
- No escribir usuario ni contraseña directamente en SotraContext.cs.
- No guardar credenciales reales en archivos del proyecto.
- User Secrets se guarda fuera del repositorio y no hace falta agregarlo al .gitignore.
- El UserSecretsId del .csproj sí puede subirse a Git.
